# 🐍 Lógica de Programação — Portugol e Python

Repositório destinado ao armazenamento e à organização dos exercícios e algoritmos desenvolvidos durante meus estudos de **Lógica de Programação**.

Os exemplos foram inicialmente desenvolvidos em **Portugol (VisuAlg)** e posteriormente convertidos para **Python**, com o objetivo de compreender e comparar a sintaxe das duas linguagens.

## 📚 Conteúdos abordados

- Variáveis e tipos de dados
- Entrada e saída de informações
- Operadores aritméticos e lógicos
- Estruturas condicionais
- Estruturas de repetição
- Estruturas de seleção
- Desenvolvimento de algoritmos

## 📁 Organização do repositório

- `portugol/` — Algoritmos originais desenvolvidos no VisuAlg.
- `python/` — Algoritmos convertidos para Python.

## 💻 Algoritmos desenvolvidos

| Nº | Algoritmo | Conteúdo |
|---|---|---|
| 01 | Análise de notas | Variáveis, entrada de dados e cálculos |
| 02 | Análise de notas com condição | Estrutura condicional |
| 03 | Análise de notas e frequência | Operadores lógicos |
| 04 | Repetição | Estrutura `while` |
| 05 | Buscas | Estrutura `match case` |

## 🛠️ Tecnologias utilizadas

- Python
- Portugol (VisuAlg)
- Visual Studio Code
- Git e GitHub

## 🎯 Objetivo

Desenvolver conhecimentos fundamentais em lógica de programação, aprimorando o raciocínio lógico e a compreensão de estruturas utilizadas no desenvolvimento de software.
